# 海岸行动 · Coastline Protocol

**Godot 4.5 原创海岛风格单人生存射击原型。** 只有一个默认玩法：你与 8 名 AI 在紧凑海岛交战，安全区不断收缩，最后存活者获胜。不再包含靶场、闯关、模式选择或训练点传送。

## 开始游戏

Windows 双击 **Launch.bat**，点击 **开始行动**。工程附有便携版 Godot，首次启动会构建 AI 通行路径，等待数秒即可。

> 从 GitHub 克隆后：先解压 `tools/godot.zip` 到 `tools/godot/`（或自行安装 Godot 4.5+），再双击 Launch.bat。

继续开发：Godot 4.5 或更新版本导入 `project.godot`，按 F5。

## 当前玩法

- 玩家 + 8 名互为敌对的 AI。AI 会自主巡逻，通过视野和遮挡判断发现目标，听枪声去最后听到的位置搜索，追击、侧移、连发、换弹和受伤撤退；AI 之间也会交火。
- AI 不是靶子：独立 `CharacterBody3D` 碰撞、地面图寻路、持枪士兵模型、步行动作和死亡倒地，不会自动复活。
- 初始生命 100、护甲 50、医疗包 2、30 发弹匣及 180 发备弹。护甲承担 35% 伤害直到耗尽；中弹可能打断治疗。
- H 使用医疗包，耗时 3 秒、恢复最多 60 生命。期间减速、不能射击或换弹，开火/奔跑/受伤会中断；成功后才消耗医疗包。
- 场景和倒地敌人会留下补给。近距离 E 拾取：60 发备弹、1 个医疗包、20 护甲，均有限额；不能隔墙拾取。不再无限自动补弹。
- 安全区前 60 秒不动，之后 180 秒从半径 132 米缩到 8 米。圈外每秒损失生命；AI 会尝试进圈。小地图显示安全区，不透视敌人。
- 淘汰所有对手获胜；玩家死亡后结算并可直接重开。暂停或切出窗口时战斗冻结。

## 场景与模型

原创低多边形海岸、房区、仓库、山坡、公路、码头与动态海面；房门、楼梯和仓库可进入。窗框、百叶、排水管、空调、路障、沙袋、吉普和货物为本地程序生成模型。敌人具备头盔、护目镜、面部肤色、护甲、背包、分段四肢与步枪，没有靶纸、底座或胸前靶心。

## 第一人称手部

左右手各由独立放样曲面构成，十根手指分别沿控制点弯曲（`tests/hands_preview.gd` 断言 `finger_count == 10`），另有掌部、虎口、手套护垫、袖口和程序布料微纹理。左手托护木、右手握握把与扳机；换弹时左手移向弹匣，弹匣同步抽出和复位。前臂延伸至画面外，避免胶囊体末端悬空。保持原有机瞄位置、弹匣容量和换弹时长。

实际观感需要说明：手指半径只有约 1 厘米，在游戏机位（距相机约 0.4 米）下十根手指会读成一团轮廓，能明确分辨的只有右手扣扳机和左手搭在护木上的那根。这是程序化建模的分辨率上限——不是扫描级写实手部，也没有骨骼 IK。要真正读出手指需要重做拓扑，属于独立的一轮工作。

## 原型边界

这是靠近吃鸡**战斗循环**的小型离线原型，不是商业游戏的完整复刻。AI 使用有限状态、地面寻路和物理射线，不等同于真人策略；复杂楼层/楼顶追击仍有限制。没有联网百人、跳伞、完整搜刮背包、多武器配件、载具驾驶或游泳；吉普是静态道具。未使用《和平精英》的官方素材、地图、商标或提取资源。
