# 海岸行动 · Coastline Protocol

**Godot 4.5 原创海岛风格单人生存射击原型。** 只有一个默认玩法：你与 8 名 AI 在紧凑海岛交战，安全区不断收缩，最后存活者获胜。不再包含靶场、闯关、模式选择或训练点传送。

## 开始游戏

Windows 双击 **Launch.bat**，点击 **开始行动**。工程附有便携版 Godot，首次启动会构建 AI 通行路径，等待数秒即可。

> 从 GitHub 克隆后：先下载 [tools/godot.zip](https://github.com/tuanzi188/CoastlineProtocol/releases/download/v0.1/godot.zip)（GitHub Releases，约 73MB）并解压到 `tools/godot/`（或自行安装 Godot 4.5+），再双击 Launch.bat。大文件已改为 Releases 分发，不入仓库。

继续开发：Godot 4.5 或更新版本导入 `project.godot`，按 F5。

## 当前玩法

- 玩家 + 8 名互为敌对的 AI。AI 会自主巡逻，通过视野和遮挡判断发现目标，听枪声去最后听到的位置搜索，追击、侧移、连发、换弹和受伤撤退；AI 之间也会交火。
- AI 不是靶子：独立 `CharacterBody3D` 碰撞、地面图寻路、持枪士兵模型、步行动作和死亡倒地，不会自动复活。
- 初始生命 100、护甲 50、医疗包 2、30 发弹匣及 180 发备弹。护甲承担 35% 伤害直到耗尽；中弹可能打断治疗。
- H 使用医疗包，耗时 3 秒、恢复最多 60 生命。期间减速、不能射击或换弹，开火/奔跑/受伤会中断；成功后才消耗医疗包。
- 场景和倒地敌人会留下补给。近距离 F 拾取：60 发备弹、1 个医疗包、20 护甲，均有限额；不能隔墙拾取。不再无限自动补弹。
- 安全区前 60 秒不动，之后 180 秒从半径 132 米缩到 8 米。圈外每秒损失生命；AI 会尝试进圈。小地图显示安全区，不透视敌人。
- 淘汰所有对手获胜；玩家死亡后结算并可直接重开。暂停或切出窗口时战斗冻结。

菜单与暂停页保留灵敏度、FOV、音量及持枪动态设置，自动保存。

## 场景与模型

原创低多边形海岸、房区、仓库、山坡、公路、码头与动态海面；房门、楼梯和仓库可进入。窗框、百叶、排水管、空调、路障、沙袋、吉普和货物为本地程序生成模型。敌人具备头盔、护目镜、面部肤色、护甲、背包、分段四肢与步枪，没有靶纸、底座或胸前靶心。

## 第一人称手部

左右手各由独立放样曲面构成，十根手指分别沿控制点弯曲（`tests/hands_preview.gd` 断言 `finger_count == 10`），另有掌部、虎口、手套护垫、袖口和程序布料微纹理。左手托护木、右手握握把与扳机；换弹时左手移向弹匣，弹匣同步抽出和复位。前臂延伸至画面外，避免胶囊体末端悬空。保持原有机瞄位置、弹匣容量和换弹时长。

实际观感需要说明：手指半径只有约 1 厘米，在游戏机位（距相机约 0.4 米）下十根手指会读成一团轮廓，能明确分辨的只有右手扣扳机和左手搭在护木上的那根。这是程序化建模的分辨率上限——不是扫描级写实手部，也没有骨骼 IK。要真正读出手指需要重做拓扑，属于独立的一轮工作。

## 移动与枪感

- 上台阶和路沿不再瞬移：身体立即抬升，镜头按同样的位移向下补偿再缓动归位，避免每级台阶都硬抖一下。
- 落地按冲击速度给一次性镜头下沉并快速恢复，高处落下不再是硬切。
- 奔跑拉高开镜外视野（+6.5°），ADS 优先级更高；蹲伏与卧倒收敛视野。
- 后坐力为确定性图案：前几发上跳最大随后收敛，水平摆动按固定 12 步序列回放；停火 0.26 秒后分两段恢复（先快速清掉大部分，再缓收最后一丝）。开镜把上跳与摆动统一降到 62%。
- 姿态影响散布：卧倒 0.5×、蹲伏 0.72×、站立 1×，腾空额外加 0.007 弧度。
- 弹匣打空时先给出空仓"咔"声再自动补上换弹，不再是无声死扳机。
- 探头（Q/E）以缓动横移相机并侧倾 6°，射击原点跟随相机所以弹道随之偏移；卧倒与奔跑时不可探头。

## AI 移动

士兵模型的移动做了同样的去顿挫处理：

- 上台阶时碰撞体仍然当帧抬升，但可见身体反向承接这段位移再缓动归位，不再整只模型"弹"过路沿（第三人称视角下这比玩家的第一人称更明显）。
- 步态相位改由**实测位移**驱动，而不是指令速度。被墙挡住时腿不再原地空转，被分离力推开时步子会相应加大。
- 落地按冲击速度弯膝压缩（膝盖与髋部带动，不整体下沉，避免脚穿进地面）。着地帧不再把垂直速度清零后丢失冲击量。
- 同伴分离力从 1.35 米硬阈值改为 1.6 米平滑衰减，并对合力做时间阻尼。原先两个 AI 卡在该距离上时力会反复开关、互相抽动。

注意最后一项会改变 AI 的实际行为：分离不再硬顶，实测同样 2 秒内 `AI moves independently` 的位移从约 1.3 米提升到约 9.3 米，AI 之间更少互相堵死。

## 音效

全部音色在加载时由 `scripts/audio_synth.gd` 从噪声源与振荡器分层合成，工程不含任何音频素材文件。总控是 autoload `Audio`（`scripts/audio_director.gd`），负责总线、发声与遮挡判定。

- 总线：Master 挂砖墙限制器；SFX / Muffled / Ambient / UI / Space 五条子总线，Muffled 经低通后汇入 SFX，Space 带混响。这个 Godot 构建没有 `AudioEffectSend`，所以混响靠独立 wet 总线与烘进采样的尾音实现。
- 枪声分四层：超声速 crack、枪口爆轰体、低频胸锤、房间尾音；三个变体随机播放，避免连射重复感。
- 敌人枪声走 3D 定位并按 130 米衰减；从听者到枪口做射线检测，被遮挡时改派 Muffled 总线（低通 + 降幅），隔墙听感不再和露天一样。
- 脚步按地面材质分四种：草地、沙地、混凝土、木质，各两个变体交替；材质在落步瞬间用射线探测。
- 补齐此前完全无声的反馈：拾取、治疗开始/完成/被打断、换弹完成、空仓干火、命中的肉感与护甲板 ping、淘汰确认、安全区收缩预警与圈外掉血、死亡、胜负结算、界面操作音。
- 环境床为海浪与风两条无缝循环（LFO 周期整除缓冲长度），并随机触发海鸟叫，避免六秒重复感。
- 每条总线固定 10 个声部，池满抢占最旧声部。

设置面板新增「枪声与脚步 / 海浪与环境 / 界面提示音」三条分轨音量，与主音量一并持久化；分轨推子叠加在总控预设的各总线基准电平上。

## 原型边界

这是靠近吃鸡**战斗循环**的小型离线原型，不是商业游戏的完整复刻。AI 使用有限状态、地面寻路和物理射线，不等同于真人策略；复杂楼层/楼顶追击仍有限制。没有联网百人、跳伞、完整搜刮背包、多武器配件、载具驾驶或游泳；吉普是静态道具。未使用《和平精英》的官方素材、地图、商标或提取资源。

## 开发工具

仓库只保留工程本体，不含工具依赖副本，需要时按需安装。

```bat
python tools\setup_gdcheck.py
```

装入 gdtoolkit 4.5.0 到 `tools\gdcheck\`（已忽略），随后可用 `tools\gdcheck\Scripts\gdlint.exe scripts` 做 GDScript 静态检查。该工具带平台相关的编译扩展，只能在本地安装，不适合随仓库分发。字体子集化用 `tools\subset_font.py`，依赖 fontTools。
